# Security Policy

## Supported Versions

Security fixes are provided for the latest release of TIDAL RPC. Please update before reporting a vulnerability.

## Reporting a Vulnerability

Report security issues privately through GitHub’s **Security → Report a vulnerability** option, if available. Please don’t include vulnerability details, credentials, or tokens in public issues.

Include the affected version, steps to reproduce the issue, and its potential impact. Reports will be reviewed as time allows; there is no guaranteed response time.
